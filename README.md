# Apple Music Clone

Aplicación web inspirada en Apple Music desarrollada con React como parte de mi formación en desarrollo Full Stack.

El proyecto implementa búsqueda de música mediante una API externa, navegación entre vistas, biblioteca de canciones y manejo de estados de carga y error.

## Funcionalidades

- Búsqueda de álbumes y artistas.
- Consumo de TheAudioDB API.
- Visualización de resultados musicales.
- Biblioteca de canciones seleccionadas.
- Prevención de elementos duplicados en la biblioteca.
- Vista de detalle mediante rutas dinámicas.
- Navegación con React Router.
- Manejo de estados de carga y error.
- Opción para reintentar solicitudes fallidas.
- Interfaz inspirada en Apple Music.

## Tecnologías

- JavaScript
- React
- React Router
- Fetch API
- Axios
- Styled Components
- CSS
- Create React App

## Instalación

Clona el repositorio:

    git clone https://github.com/MarkBettley/apple-music-clone.git

Entra al proyecto:

    cd apple-music-clone

Instala las dependencias:

    npm install

Ejecuta la aplicación:

    npm start

## Build de producción

    npm run build

El proyecto genera correctamente una compilación optimizada para producción.

## API

La aplicación utiliza TheAudioDB para realizar búsquedas de información musical.
